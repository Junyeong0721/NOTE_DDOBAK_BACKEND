# 2026-11-11 3주차: 글씨 보정 (목표 글씨체로 바꾸기)

## 만든 기능
- 설정에서 목표 글씨체 고르기(미리보기 카드 5종, 기본 고운돋움) — 노트 보정과 연습 모드 공용, 기기에 저장
- 한 줄을 다 쓰면 그 줄을 인식해 **보정안**(목표 글씨체 미리보기)을 화면 아래 막대로 보여 주고 [바꾸기]
- 바꾼 뒤 글자 칩을 눌러 **그 글자만 원래 글씨로** 되돌리기, [보정 취소]
- 올가미: 고른 글씨 [보정], 보정된 글씨 [글자 고르기] [원래 글씨로]
- 지우개로 보정된 글자를 건드리면 그 글자가 통째로 지워짐
- 설정에서 자동 보정안을 끄면 올가미로 고른 글씨만 인식(하루 인식 횟수 절약). 자동은 다음 줄로 넘어갈 때 또는 펜을 4초 멈출 때만
- `start-dev.bat`: 백엔드 창 한글 로그 깨짐 해결(`chcp 65001`)

## AI에게 준 요청
- "유저가 고를 수 있게 하고 싶은데" (목표 글씨체를 하나로 정하지 않고 사용자 선택)
- 11/3에 정한 보정 방식: 자동 줄 단위 + 글자별 원래대로 + 올가미 보정, 원본은 숨기기만

## 받은 결과 요약
- **원본 보존 설계**: 페이지에 `corrections: [{ id, fontId, chars: [{ ch, strokeIds, off? }] }]`만 저장. 보정 글자의 위치·크기는 저장하지 않고 그 글자를 이루는 획의 *지금* 위치로 매번 계산 → 노트 정리·올가미 이동·실행 취소를 따로 처리할 필요가 없음
- **OCR 결과 → 내 획 연결**: Vision이 준 글자 상자(줄 이미지 픽셀)를 줄 이미지를 만들 때의 원점·배율로 페이지 좌표로 되돌리고, 각 획을 가로 가운데가 들어가는(없으면 가장 가까운) 글자에 배정
- **글자 그리기**: 글꼴 파싱 없이 캔버스 `fillText` + 웹 글꼴. 기울어진 줄은 글자 가운데들에 직선을 맞춰 따라감
- **글꼴 선정**: Google Fonts(OFL) 6개 후보 중 한글 11,172자가 다 있는 5개만 (개구는 2,350자라 제외). fontTools로 한글·영문·기호만 남겨 3~13MB → 0.4~1.3MB woff

## 오류와 해결
| 오류 | 원인 | 해결 |
| --- | --- | --- |
| 보정 글자가 손글씨보다 작게 나옴(하이멜로디) | 글꼴마다 한글이 글꼴 칸(em)에서 차지하는 높이가 다름 (하이멜로디 '가' 0.45em, 고운돋움 0.85em) | 브라우저에서 기준 글자 '가'의 실제 높이를 재서 크기를 맞추고, 글자마다 실제 높이 가운데를 줄 가운데에 맞춤 |
| 처음 잰 기준을 '한글보정'으로 했더니 보통 글자가 작아짐 | '보·정'처럼 위아래로 긴 글자가 기준 높이를 키움 | 기준 글자를 '가'로 |
| 폭 넓은 글꼴은 빽빽한 손글씨에서 글자끼리 겹침 | 글자 폭이 손글씨 간격보다 넓음 | 이웃 글자 가운데까지 거리의 95%를 넘으면 그만큼만 줄임 |
| 페이지에 보정 정보를 추가했더니 저장 때 사라질 위험 | 기존 코드가 페이지를 `{ strokes }`로 새로 만들던 곳이 여러 군데 | 페이지를 바꾸는 곳을 `withStrokes`(지워진 획의 보정 정리 포함)로 통일, 불러오기에서 `corrections` 기본값 `[]` |
| `start-dev.bat` 수정 시 깨진 글자 | 저장소에서는 UTF-8, 작업 폴더에서는 CP949(`.gitattributes`) | CP949로 읽고 써서 수정 |

## 내가 이해한 핵심 3줄
1. 원본 데이터는 그대로 두고 "덧씌우는 정보"만 저장하면 되돌리기·편집이 쉬워진다.
2. 저장하는 값은 최소로, 보이는 값(위치·크기)은 매번 계산하면 다른 기능과 엮여도 어긋나지 않는다.
3. 글꼴마다 글자 크기 비율이 달라서, 숫자를 고정하지 말고 실제로 재서 맞춰야 한다.

## 검증
- 프론트 테스트 127개 통과 (보정 로직 15개, 글꼴·설정 7개, 그리기 2개 추가)
- Playwright 화면 확인: 설정 저장 → 한 줄 쓰고 다음 줄 → 보정안 → 바꾸기 → 글자 하나 원래대로 → 올가미 원래 글씨로 → 올가미 보정 → 지우개로 글자 지우기 → 노트 정리 → 썸네일, 오류 없음
- 5개 글꼴 모두 같은 손글씨에 적용해 크기·줄 맞춤 확인
