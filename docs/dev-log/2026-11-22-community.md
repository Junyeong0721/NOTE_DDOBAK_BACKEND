# 2026-11-22 노트 공유 커뮤니티

## 정한 것 (사용자)
- 넣는 것: 공개하기·둘러보기·읽기 + **좋아요, 내 노트로 가져오기, 댓글, 검색·과목 필터**
- **또박 회원만** (로그인 필요, 링크 공개 없음)
- **공개하면 그 순간 모습으로 고정**, 노트를 고친 뒤 **[공개본 업데이트]**를 눌러야 바뀜. 제목·과목·소개는 언제든 수정
- 신고: 한 사람 한 번, **3명이면 자동 숨김** (관리자 화면 없음)
- 설계: `docs/superpowers/specs/2026-11-22-community-design.md`, 계획: `docs/superpowers/plans/2026-11-22-community.md`

## 만든 것
- 노트 위쪽 [공개] → 공개 창: 제목(기본 노트 제목), 과목(폴더 이름 + 커뮤니티 과목 추천 칩), 한 줄 소개
  - 공개 중: ♥·댓글·가져감 수, "공개한 뒤에 노트가 바뀌었어요" [공개본 업데이트], 신고로 숨겨졌으면 안내, [공개 그만하기](한 번 더 확인), [커뮤니티에서 보기]
  - 빈 노트(획 0)는 공개 안 됨. 자동 저장이 끝나기 전엔 공개·업데이트를 잠깐 막음(서버의 노트를 복사하므로)
- 홈 [커뮤니티]: 검색(제목·과목·소개·요약), 최신순·인기순, 과목 칩 15개, 카드 20개씩 [더 보기]
- 공개 노트 보기: 요약, 좋아요, 내 노트로 가져오기 → [열기], 신고(이유 3가지), 읽기 전용 필기(보정 글자는 쓴 사람의 글씨체), 댓글(500자, 쓴 사람·글 주인만 삭제)
- 서버: Flyway **V5** (`community_post`, `post_like`, `post_comment`, `post_report`), `/api/notes/{id}/publish`, `/api/community/...`
  - 원본 노트를 지워도 공개본은 남음(`note_id` ON DELETE SET NULL), 회원을 지우면 공개본·좋아요·댓글·신고도 같이 지워짐
  - 좋아요·댓글·신고 수는 바꿀 때마다 같은 트랜잭션에서 실제 줄 수로 다시 셈 → 연타·두 번 요청에도 정확
  - 숨겨진 글은 주인이 아니면 목록·과목·검색·보기·댓글·좋아요·가져오기 모두 404

## 겪은 문제
- 글자 수: 처음엔 코드포인트로 셌는데 테스트 DB(H2)는 UTF-16 길이로 재서 이모지 제목이 DB에서 터짐 → 화면 `maxlength`와 같은 `String.length` 기준으로 통일 (이모지는 2자)
- 검색 이스케이프: MySQL은 문자열 안의 `\`를 이스케이프로 읽어서 `escape '\'`가 깨질 수 있음 → 이스케이프 글자를 `!`로
- MockMvc `get("...?q=%25")`는 주소를 한 번 더 인코딩함 → 테스트에서 `.param()`으로 넘김

## 확인
- 백엔드 130개(새로 20개: 공개·정보 수정·업데이트·outdated·그만하기·원본 삭제·회원 삭제, 목록 정렬·페이지·과목·검색 `%`/`_`, 좋아요 두 번, 가져오기 후 원본 바뀌어도 그대로, 댓글 권한 403, 신고 409·3명 숨김, 로그인 401)
- 프론트 단위 테스트 추가(API 경로, 과목 추천, 카드 글·숫자 줄임)
- Playwright 두 계정(+신고용 2개): A 공개 → B 과목·검색·읽기·좋아요·댓글·가져오기 → A 수정 후 업데이트(좋아요·댓글 유지) → B 가져온 노트 그대로 → 신고 3명 숨김(주인에겐 "숨겨짐") → 폰 크기 가로 스크롤 없음
