# 2026-11-11 H2 → MySQL, 표는 SQL로 직접 설계(Flyway)

## 만든 기능
- 실제 데이터는 PC에 설치한 MySQL 8.4(`ddobak` 데이터베이스, `ddobak` 계정)에 저장. 비밀번호는 `secret.yaml`
- 테스트는 그대로 메모리 H2 (빠르고 MySQL 없이도 돌아감)
- 설치·설정 안내 `docs/mysql-setup.md`
- **표 설계를 SQL로**: `db/migration/V1__create_tables.sql` — 회원·폴더·노트, 외래 키(회원 삭제 시 노트·폴더 함께 삭제, 폴더 삭제 시 노트는 미분류), 고유 제약(이메일, 소셜 회원 번호), 목록 정렬용 인덱스(user_id, updated_at), 칸마다 설명(COMMENT)
- 서버가 켜질 때 Flyway가 설계 파일을 순서대로 실행, 서버는 엔티티와 표가 맞는지만 확인(`ddl-auto: validate`)

## AI에게 준 요청
- "DB도 만들어야 하는 거 아니야?" → "지금 바꾸는 게 좋을 것 같아"
- "MySQL에서 테이블 만들고 DB 구성해서 데이터를 넣는 게 아니라 불러오는 용도로만 쓴다는 건가?" → 코드가 표를 만드는 방식과 SQL로 직접 설계하는 방식을 비교 → "직접 설계하는 방식이 좋을 것 같아"

## 받은 결과 요약
- 표는 따로 만들 필요 없음: `ddl-auto: update`로 서버가 켜질 때 엔티티에 맞춰 만든다. 사람이 할 일은 MySQL 설치 + 빈 데이터베이스·계정 만들기
- AI 환경에서 MySQL을 띄울 수 없어서, **엔티티로 MySQL용 표 정의(DDL)를 뽑아 미리 검토** → 실제 PC에서 터졌을 문제 2개를 먼저 찾음

## 오류와 해결
| 오류 | 원인 | 해결 |
| --- | --- | --- |
| 필기 데이터 칸이 MySQL에서 `tinytext`(255바이트) → 노트 저장 실패 예정 | `@Lob` + `@Column`에 길이를 안 주면 기본 255로 잡힘. H2에서는 티가 안 났음 | 길이를 크게 줘서 `longtext`, 다시 255가 되지 않게 테스트(`NoteSchemaTest`) |
| 폴더 색·가입 방식이 MySQL `enum` 칸 | Hibernate가 `EnumType.STRING`을 MySQL enum으로 만듦 → 나중에 값(새 색, 새 소셜 로그인)을 추가하면 `ddl-auto: update`가 칸을 안 고쳐서 저장 실패 | `@JdbcTypeCode(SqlTypes.VARCHAR)`로 글자 칸 |

| 테스트가 설계 SQL로 표를 만들자 `content` 칸 종류가 안 맞는다며 실패 | 엔티티는 `@Lob`(CLOB)을 기대하는데 MySQL 호환 H2는 LONGTEXT를 일반 글자 칸으로 보고함. 실제 MySQL에서도 같은 종류의 불일치가 날 수 있음 | `@Lob` 대신 `columnDefinition = "longtext"`로 명시 → MySQL·H2 둘 다 맞음 |
| 테스트를 한꺼번에 돌리면 "이미 있는 표" 오류 | 설정이 다른 테스트가 같은 메모리 DB에 설계 SQL을 또 실행 | 테스트 설정마다 새 메모리 DB(`${random.uuid}`) |
| AI 환경에 Flyway 라이브러리가 없음(Maven 차단) | — | 테스트는 Flyway 대신 Spring이 같은 설계 SQL을 직접 실행(`spring.sql.init`) + `validate` → 설계 SQL과 코드가 맞는지는 AI 환경에서도 검증. Flyway 자체는 PC에서 처음 실행 |

## 내가 이해한 핵심 3줄
1. 개발용 DB(H2)에서 되는 게 실제 DB에서도 된다는 보장은 없다 — 실제 DB 기준 표 정의를 뽑아서 확인한다.
2. 큰 글자 데이터는 칸 크기를 명시한다.
3. enum은 DB 기능보다 글자로 저장하는 쪽이 바꾸기 쉽다.
4. 표 설계를 SQL 파일로 두면 설계가 문서가 되고, 바뀐 기록(V1, V2…)이 남는다. 서버는 "맞는지 확인"만 한다.

## 검증
- 백엔드 테스트 68개 통과 — 모든 테스트가 설계 SQL로 만든 표(MySQL 호환 모드)에 대해 엔티티 검증(`validate`) 후 실행
- PC에서 MySQL 설치 후 실제 연결 확인 예정
